# Schemas

- [Asset Schema](asset-schema.yaml) - Contrato canónico para documentar assets reutilizables con procedencia y referencias.
- [Component Schema](component-schema.yaml) - Contrato semántico `component` versión `0.6` para componentes del design system.
- [Foundation Schema](foundation-schema.yaml) - Contrato `foundation` versión `0.2` para fundamentos visuales y su gobernanza.
- [Pattern Schema](pattern-schema.yaml) - Contrato `pattern` versión `0.2` para patrones compuestos y su comportamiento.
- [Token Schema](token-schema.yaml) - Contrato `token` versión `0.3` compatible con `DTCG-2025.10`.
