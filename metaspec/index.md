# MetaSpec

- [Schemas](schemas/) - Contratos estructurales para assets, components, foundations, patterns y tokens.
- [Taxonomy](taxonomy/) - Vocabularios controlados y reglas de clasificación canónica.
- [Ontology](ontology/) - Modelo semántico general del sistema de especificaciones.
- [Policies](policies/) - Políticas editoriales y de gobierno de entidades.
- [Quality](quality/) - Quality gates para revisar consistencia y portabilidad.
- [Tokens](tokens/) - Guía operativa para importación y normalización de tokens.
- [Semantic Intent](semantic-intent/) - Definición del propósito del producto, roles y entidades del dominio.
