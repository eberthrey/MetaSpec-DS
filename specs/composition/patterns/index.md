# Patterns

- [Waup Location Card](waup_location_card.yaml) - Tarjeta informativa e interactiva para mostrar y editar la dirección de recojo.
- [Waup Navigation Header](waup_nav_header.yaml) - Encabezado interno con acción de retroceso y título contextual.
- [Navegación Inferior de Onboarding](waup_onboarding_navigation.yaml) - Patrón que combina progreso por pasos con CTA principal del onboarding.
- [Waup Option Selector Group](waup_option_selector_group.yaml) - Grupo de opciones seleccionables para configuraciones como duración u horarios.
- [Waup Owner Header](waup_owner_header.yaml) - Encabezado contextual del home del dueño con saludo, perfil y notificaciones.
- [Waup Pet Select Carousel](waup_pet_select_carousel.yaml) - Carrusel de selección múltiple de mascotas con límite y acción para agregar nuevas.
- [Waup Recent Walk Card](waup_recent_walk_card.yaml) - Tarjeta resumen del último paseo completado con datos operativos clave.
- [Waup Shortcut Card](waup_shortcut_card.yaml) - Tarjeta compacta de acceso rápido para navegación desde dashboards.
