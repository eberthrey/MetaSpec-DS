# Owner Flows

- [waup_add_payment](waup_add_payment.yaml) - Formulario para registrar una nueva tarjeta de pago del dueño.
- [waup_add_pet](waup_add_pet.yaml) - Formulario para registrar una nueva mascota del dueño.
- [waup_match_candidates](waup_match_candidates.yaml) - Pantalla que muestra la terna cerrada de paseadores disponibles.
- [waup_match_loading](waup_match_loading.yaml) - Estado de espera mientras se buscan y filtran paseadores compatibles.
- [waup_owner_home](waup_owner_home.yaml) - Dashboard principal del dueño con accesos rápidos, mascotas y paseos recientes.
- [waup_payment_list](waup_payment_list.yaml) - Listado de tarjetas guardadas y acceso para agregar nuevas.
- [waup_payment_processing](waup_payment_processing.yaml) - Resumen final de cobro con tarifa, comisión y tarjeta activa.
- [waup_pet_detail](waup_pet_detail.yaml) - Perfil detallado de una mascota con hero, atributos y datos de cuidado.
- [waup_pets_list](waup_pets_list.yaml) - Lista de mascotas registradas con acceso a detalle y alta de nuevas mascotas.
- [waup_ride_confirmed](waup_ride_confirmed.yaml) - Confirmación exitosa del pago y liberación de datos del paseador.
- [waup_ride_request_setup](waup_ride_request_setup.yaml) - Configuración de una solicitud de paseo con mascotas, duración, recojo e instrucciones.

# Walker Flows

- [waup_add_payout](waup_add_payout.yaml) - Formulario para registrar una nueva cuenta de cobro del paseador.
- [waup_credits](waup_credits.yaml) - Monedero del paseador con saldo acumulado, historial de retiros y CTA de retiro.
- [waup_payout_list](waup_payout_list.yaml) - Listado de cuentas de cobro y gestión de destinos de retiro.
- [waup_walker_home](waup_walker_home.yaml) - Dashboard principal del paseador con finanzas, disponibilidad y solicitudes.
- [waup_withdraw_request](waup_withdraw_request.yaml) - Formulario para solicitar retiro hacia una cuenta bancaria guardada.

# Shared And Cross-Role

- [waup_ride_history](waup_ride_history.yaml) - Historial compartido de paseos completados y facturados.
