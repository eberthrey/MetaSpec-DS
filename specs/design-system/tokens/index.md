# Tokens

- [Base](base.yaml) - Tokens primitivos de color, radius y otros valores base normalizados para consumo interno.
- [Semantic](semantic.yaml) - Tokens semánticos de intención UI construidos sobre los primitivos base.

## Exported Contracts

- `spacingTokenMap` - contrato tipado de espaciados consumido por layout primitives.
- `radiusTokenMap` - contrato tipado de radios consumido por layout y componentes.
- `typographyStyleMap` - contrato tipado de estilos textuales consumido por `Typography`.
- `iconSizeTokenMap` - contrato tipado de tamaños de icono consumido por `Icon`.
