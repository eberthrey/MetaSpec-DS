# Components

## Implemented From Figma

- [Avatar](avatar.yaml) - Implementado como `Avatar`; representación visual circular de usuarios, paseadores o mascotas.
- [Badge (Placa / Etiqueta)](badge.yaml) - Implementado como `Badge`; contenedor compacto para estados, recuentos y etiquetas destacadas.
- [Button Icon (Botón de Icono)](button_icon.yaml) - Implementado como `ButtonIcon`; botón compacto solo con icono para acciones secundarias o de cabecera.
- [Carrusel (Deslizador / Swiper)](carousel.yaml) - Implementado como `Carousel`; contenedor de desplazamiento horizontal para colecciones homogéneas.
- [Checkbox (Casilla de Selección)](checkbox.yaml) - Implementado como `Checkbox`; control de selección binaria para listas y grupos.
- [Chip (Pastilla Seleccionable)](chip.yaml) - Implementado como `Chip`; pastilla interactiva para filtros y grupos de selección.
- [Header (Encabezado)](header.yaml) - Implementado como `Header`; encabezado principal con contexto de usuario, notificaciones y avatar.
- [Input Field (Campo de Entrada)](input.yaml) - Implementado como `Input`; campo de entrada para texto estructurado y notas cortas.
- [Input Search (Campo de Búsqueda)](input_search.yaml) - Implementado como `InputSearch`; campo de búsqueda con icono de lupa y altura fija.
- [Map (Visor de Mapa)](map.yaml) - Implementado como `Map`; visor de mapa placeholder de solo lectura o ajuste.
- [Photo Uploader (Cargador de Fotos)](photo_uploader.yaml) - Implementado como `PhotoUploader`; grilla para carga y visualización de imágenes.
- [Service Type Switch (Selector de Tipo de Servicio)](service_type_switch.yaml) - Implementado como `ServiceTypeSwitch`; control segmentado para alternar entre servicio inmediato y programado.
- [Step Indicator (Indicador de Pasos)](step_indicator.yaml) - Implementado como `StepIndicator`; indicador visual del progreso en flujos multi-step.
- [Walk Card (Tarjeta de Paseo)](walk_card.yaml) - Implementado como `WalkCard`; tarjeta resumen para paseos recientes, históricos o programados.
